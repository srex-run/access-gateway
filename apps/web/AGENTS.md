# 前端工作规范

本目录的前端修改须遵守 [模块实现文档](../../docs/02-ModuleImplementation.md#前端工程)，尤其是“辅助说明展示规范”。

- 辅助说明一律使用 `@/shared/ui/help-popover` 的 `HelpPopover`，通过对应字段或操作旁的 `?` 展示，不在页面常驻铺开说明段落，也不以 `Form.Item extra/help` 或 `Alert` 代替问号说明。
- 同一字段的说明集中在一个问号内，按当前选择展示适用内容；其中的配置链接必须保留可点击。使用明确的 `title`，复用组件的键盘操作和可访问名称。
- 实时错误、表单校验和阻塞状态直接展示。
- 审批流程预览固定以“提交申请”为首节点、“审批结束”为尾节点，中间按配置展示审批节点，仅显示节点名称与顺序箭头。资产创建和编辑中由“查看审批流程”入口打开弹窗；审批流程编辑页的实时预览放在表单下方。
- 小范围修改只运行直接相关的最小检查；同一会话不重复读取已读文档，需要核实最新内容时只读必要片段。
