# MySQL TLS Certificate Bundle

Generated by access-gateway for the DNS names and IP addresses entered in the
audit rule. The server certificate and CA use RSA-2048 keys. The CA private key
is not included. Keep `server.key` private.

The audit rule receives the matching asset CA automatically when this bundle
is generated. Save that rule. MySQL must load `server.crt` and `server.key`
before the gateway can verify it. Open a new access-gateway session after both
changes; existing sessions retain their original audit rule.

## Linux

Extract this archive on the MySQL server and run:

```sh
sh install-mysql-tls.sh --dry-run
sudo sh install-mysql-tls.sh
sudo systemctl restart mysql
```

Use `mysqld` instead of `mysql` for the service name on systems that require it.
The installer creates `/etc/mysql/access-gateway-tls` and writes
`/etc/mysql/conf.d/access-gateway-tls.cnf`. It refuses to overwrite an existing
installation. It does not restart MySQL or change passwords or database data.

For a different MySQL configuration include directory or service account:

```sh
sudo env MYSQL_TLS_CONFIG=/etc/my.cnf.d/access-gateway-tls.cnf \
  MYSQL_TLS_USER=mysql MYSQL_TLS_GROUP=mysql sh install-mysql-tls.sh
```

`MYSQL_TLS_DIR` can also select a different certificate directory. MySQL must
be able to read it, including any AppArmor or SELinux restrictions. Confirm that
the chosen configuration directory is included by your MySQL configuration.

## Docker

For an existing container named `mysql`, copy the extracted bundle into it:

```sh
docker cp . mysql:/tmp/access-gateway-mysql-tls
docker exec -u 0 mysql sh /tmp/access-gateway-mysql-tls/install-mysql-tls.sh
docker restart mysql
```

Files copied into a container survive a restart but not container replacement.
For Docker Compose or Kubernetes, persist the certificate directory and include
the supplied `mysql.cnf` in the container's MySQL configuration. Mount the files
at the paths in `mysql.cnf`; give the container's MySQL user read access to
`server.key` without making it world-readable.

## Verify

Run on the MySQL server or in the container after restarting:

```sh
mysql -u root -p -e "SHOW GLOBAL VARIABLES WHERE Variable_name IN ('have_ssl', 'ssl_ca', 'ssl_cert', 'ssl_key');"
```

`have_ssl` should be `YES`, and the certificate paths should reference this
bundle. The installer enables server TLS without requiring TLS for all other
database clients.
